# agent-governance · 多智能体 Markdown 治理体系

由子星明编排的多智能体治理实践方法论：以纯 Markdown 模板定义 Agent 的角色、边界与协作关系，零代码、可版本化、可审计。

## 模板清单
| 文件 | 作用 |
|---|---|
| 01-Agent 编排治理 | 多 Agent 编排总体治理框架 |
| 02-SOUL_template | Agent 灵魂 / 人格模板 |
| 03-CONSTITUTION_template | Agent 宪法 / 底线约束模板 |
| 04-AGENTS_template | Agent 角色定义模板 |
| 05-AGENTS_template(编排上下文路由) | 编排上下文路由模板 |
| 06-ceo_template | CEO / 总控角色模板 |
| 07-路由 系统导航_template | 系统导航 / 路由模板 |

## 设计原则
- 参照系可复用：SOUL / CONSTITUTION / AGENTS 三层分离
- 治理即文档：所有约束以 Markdown 落地，随仓库版本化
- 实战输出：源自子星明多智能体治理实践
